=== Saputo Law ===

Version: 0.5.26

A custom block theme for the Saputo Law proof of concept.

== Installation ==

1. Upload the saputo-law folder to wp-content/themes, or upload a zip from Appearance > Themes.
2. Activate Saputo Law.
3. On first activation, the theme creates the starter pages, configures the homepage and article archive, sets Post name permalinks, removes untouched WordPress sample content, and updates the site title.
4. Existing pages are never overwritten, except the Paul and Nick attorney pages, which are refreshed so their portraits stay in place.
5. Review all seeded copy, links, recognitions, case results, and disclaimers before presenting or publishing.
6. Configure a secure contact-form provider on the Contact page.

The header keeps four items. Attorneys opens a partner dropdown. Results opens Case Results and Testimonials.

== Source assets ==

The package includes selected attorney photographs and current recognition marks copied from the firm's public website. Confirm permission, award-license terms, dates, and preferred crops before production launch.

The homepage hero uses the firm’s original Texas and United States flags photograph from saputo.law, the same image used as the Facebook cover. Confirm continued permission before production launch.
